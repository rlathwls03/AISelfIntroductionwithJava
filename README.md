## 🎯 작품 개요

AI-ntro는 AI 기술을 활용해 사용자의 정보를 입력받고, 채용 공고에 맞는 자기소개서를 자동으로 생성하며, 이를 모바일 기기 내에서 PDF로 저장 및 활용 가능하도록 구현한 어플리케이션입니다.  
현대 취업 시장에서는 수많은 자기소개서를 빠르게, 그리고 정확하게 준비해야 하고 많은 지원자들은 자기소개서 작성에 어려움을 겪고 있으며, 반복적인 포맷 작성에 많은 시간을 소비하고 있습니다. 이를 해결하기 위해 이 프로젝트를 기획하였습니다.

## ✨ 주요 기능 및 기대 효과

- **사용자 맞춤형 자기소개서 자동 생성**  
  사용자가 입력한 학력, 자격증, 희망 직무 등의 정보를 기반으로 AI가 구조화된 자기소개서를 자동 작성, 작문 부담을 줄이고 시간 절약 효과 발생

- **온디바이스 AI의 활용을 통한 개인정보 보호 강화**  
  AI모델이 클라우드가 아닌 모바일 기기 내에서 동작함으로써, 민감한 개인정보(이름, 연락처, 학력 등)가 외부로 전송되지 않음, 사용자는 더욱 안심하고 민감 정보를 입력할 수 있음 

- **오프라인 환경에서도 완전한 기능 수행**  
  인터넷 연결 없이도 AI 모델이 작동하고 결과를 생성하므로 지하철, 해외, 비행기 등 네트워크가 불안정한 환경에서도 사용 가능, 실시간 데이터 요청이 없어 서버 비용 절감 및 빠른 응답 속도 제공

- **로컬 저장소 기반 이력 관리**  
  생성된 자기소개서는 JSON 형태로 기기에 저장되어 편리하게 열람, 수정, 삭제 가능, 사용자는 앱 내에서 다수의 자기소개서를 관리할 수 있어 실용성 높음
 - **비전문 사용자도 손쉽게 활용 가능**  
  복잡한 인터페이스 없이 Android Studio 기반의 직관적인 UI 제공, AI를 활용한 문서 생성을 처음 접하는 사용자도 간편하게 활용 가능
